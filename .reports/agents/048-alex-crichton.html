The host-plugin boundary is entirely stringly-typed: WasmRuntime::call_export takes an arbitrary export_name: &str and raw bytes, and every payload is ad-hoc serde_json::Value. Drift has already shipped — docs/extension-sdk.md documents a resolve_ref host function that no host implements, while the real export was named host_query_graph without any compile-time check catching the mismatch. A plugin calling the documented name gets a runtime trap instead of a compile error. A WIT package (wit-bindgen) on both sides, or at minimum one shared generated types crate consumed by host and plugins, would make the contract checked at build time and self-documenting for AI agents reading the interface.
