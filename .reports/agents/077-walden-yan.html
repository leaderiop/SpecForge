Every prompt here hands the model a script where the assistant turn contains data the model never said - kind guides, entity lists, the entire unanalyzed file dump - and hosts trim or reinterpret assistant turns, so your reference material sits in the least stable slot while the user turn carries one sentence. Swap the roles so instruction plus payload ride the user message, or emit the payload as an embedded resource referenced from the prompt; you already register specforge://context, so the resource path is a small change. Evidencecrates/specforge-mcp/src/prompts/infer.rscrates/specforge-mcp/src/tools/query.rscrates/specforge-emitter/src/context.rs; brief.rs

Every prompt in infer.rs (get_overview, get_kind_scoped, get_file_scoped, get_plan, get_workflow) puts the reference payload - kind guides, existing entity IDs, unanalyzed file lists - into an assistant-role message, so the model is handed data-it-already-said that it never said. Hosts commonly trim, summarize, or reinterpret assistant turns, and models treat assistant content as prior commitments, so instructions smuggled this way can lose authority mid-session or be silently dropped by context compaction. The user turn carries only a one-line instruction while the payload - the material that must not vanish - sits in the least stable slot. Swapping roles or emitting the payload as an embedded resource (specforge://context is already a registered resource URI) fixes this with a shape change only.

Explain like I'm 10

The prompt hands the model a script that says 'and here is what you already said...' — putting the reference material in the model's own mouth. Some hosts trim or reinterpret assistant turns (and treat them as commitments the model made), so instructions delivered this way can lose authority or vanish mid-session. Put the reference material where readers look: user side or an attached resource.

Proposed solution. Swap roles (user message carries instruction + payload), or return the payload as an embedded resource (specforge://context scoped to kind) referenced from the prompt, keeping the assistant turn empty.
