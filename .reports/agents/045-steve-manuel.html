Auditor review

The four include_bytes! wasm paths are a build-system landmine — I appreciate the ambition of embedding real Wasm builtins rather than stubbing them, but a repo where a fresh clone cannot run cargo build fails the first thing any contributor or AI agent tries. First fix: a build.rs guard in specforge-extism that cross-compiles the four extension crates (with a crisp rustup-target error if wasm32-unknown-unknown is missing) and a CI job that builds from a clean checkout. Until then the embedded-Wasm story is unshippable.

Evidencebuiltins.rs:3-6

crates/specforge-extism/src/builtins.rs hard-codes four include_bytes! paths into extensions/*/target/wasm32-unknown-unknown/release/*.wasm — artifacts that only exist after each extension crate has been cross-compiled. Nothing in the workspace builds them: a fresh clone fails to compile specforge-extism at the macro expansion with a 'couldn't read ...: No such file or directory' error, before any cargo guidance can help. A build.rs guard that either builds the four crates or fails with precise instructions, plus a CI clean-checkout build, turns this into a self-healing bootstrap.

use std::env;
use std::path::Path;
use std::process::Command;

const EXTENSIONS: &[(&str, &str)] = &[
    ("product", "specforge_ext_product.wasm"),
    ("software", "specforge_ext_software.wasm"),
    ("governance", "specforge_ext_governance.wasm"),
    ("formal", "specforge_ext_formal.wasm"),
];

fn main() {
    let manifest_dir = env::var("CARGO_MANIFEST_DIR").unwrap();
    let workspace = Path::new(&manifest_dir).join("../..");
    for (name, artifact) in EXTENSIONS {
        let wasm = workspace.join(format!("extensions/{name}/target/wasm32-unknown-unknown/release/{artifact}"));
        if wasm.exists() { continue; }
        println!("cargo::rerun-if-changed=extensions/{name}/src");
        let status = Command::new("cargo")
            .args(["build", "--release", "--target", "wasm32-unknown-unknown"])
            .current_dir(workspace.join(format!("extensions/{name}")))
            .status()
            .expect("failed to spawn cargo for extension build");
        assert!(status.success(), "failed to build builtin extension '{name}'; run: rustup target add wasm32-unknown-unknown");
    }
}
