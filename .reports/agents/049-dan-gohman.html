Auditor review

This sandbox would not pass review: file_system_access defaults to true, an empty allowed_paths means 'everything', starts_with has no component boundary, and — most damning — the carefully merged most-restrictive-wins policy is computed and then never handed to instantiate() or host_read_file, which hard-code the defaults. The merge logic in configure_sandbox_policy is genuinely well-designed, which makes it worse that it is decorative. Fix order: empty-equals-deny, component-wise compare, thread merged policy through HostContext and PluginBuilder, then epoch-based enforcement.

Deny-by-default exists only on paper. default_sandbox_policy() sets file_system_access=Some(true) with an empty allowed_paths; is_path_allowed then returns true for ANY path when allowed_paths is empty, and even with entries uses a bare str::starts_with so '/a' permits '/abc' (no component boundary). Meanwhile configure_sandbox_policy computes a merged most-restrictive policy that instantiate() never sees — PluginBuilder is built with no manifest policy at all — and host_context.rs:140 hard-codes `let policy = default_sandbox_policy()` in host_read_file, so a plugin's negotiated sandbox_policy is stored but never enforced. A malicious or buggy plugin can read any file the host process can. Fixes: empty means deny, canonicalize and compare path components, thread the merged SandboxPolicy through ExtismRuntime into both PluginBuilder and the host functions, and enforce memory/time at the Wasmtime level.

/// Check if a filesystem path is allowed by the sandbox policy.
/// Deny-by-default: file_system_access must be Some(true) AND allowed_paths
/// must list an ancestor of `path`, compared component-wise.
pub fn is_path_allowed(path: &str, policy: &SandboxPolicy) -> bool {
    if policy.file_system_access != Some(true) {
        return false;
    }
    if policy.allowed_paths.is_empty() {
        return false;
    }
    let path = std::path::Path::new(path);
    policy.allowed_paths.iter().any(|allowed| {
        let allowed = std::path::Path::new(allowed);
        path.components().zip(allowed.components()).all(|(a, b)| a == b)
            && path.components().count() >= allowed.components().count()
    })
}
