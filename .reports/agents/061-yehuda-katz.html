pub fn resolve_set(root: &str, registries: &[RegistryConfig], client: &dyn RegistryClient)
    -> Result<Vec<ResolvedExtension>, Diagnostic>
{
    let mut chosen = resolve_transitive(root, registries, client)?;
    loop {
        let manifests: Vec<ManifestV2> = chosen.iter().map(|e| e.manifest.clone()).collect();
        match validate_peer_dependencies(&manifests).into_iter().next() {
            None => return Ok(chosen),
            Some(diag) => backtrack_or_report(&mut chosen, diag, registries, client)?,
        }
    }
}

Explain like I'm 10

Every band member picking their own song is fine individually, a mess together — and today the band only finds out at rehearsal (compile-time E027). A bandleader should pick versions together before the concert. Checking who a complaint is about by searching their name in the sentence is as fragile as it sounds.

Proposed solution. Add a resolution pass over the peer-DAG (greedy highest-match with peer re-validation, backtracking on E027) before install, with structured conflict reporting; replace substring diagnostic filtering with (name, diagnostic) pairs.
