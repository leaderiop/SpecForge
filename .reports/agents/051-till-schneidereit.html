Auditor review

'Wasm is the only extension runtime' is a claim the code refutes three times over — native BuiltinExtension, native emitter builtins with six names, and a CompositeRuntime that silently lets builtins shadow user Wasm of the same name. Silent shadowing is the dangerous part: someone's custom product extension simply never runs and nothing tells them. Either commit to the embedded-Wasm-only path (my preference — it deletes the trait and the emitter list) or at minimum raise an E-code on collision.

'Wasm is the only extension runtime' fails three ways. BuiltinExtension (builtin.rs) implements native Rust extensions behind a BuiltinRuntime whose has_cached_module is trivially true; specforge-emitter has its own KNOWN_BUILTINS list with six names including native RustExtension/TypeScriptExtension never shipped as Wasm; and CompositeRuntime::call_export tries the builtin map FIRST and only falls through to Extism on kind == "not_found" — so a user Wasm extension named @specforge/product is silently shadowed by the native one with no diagnostic. Users believe they are running the embedded Wasm modules while actually executing in-process Rust. Either make builtins genuinely single-path (always the embedded .wasm) or document the tiers honestly, and emit an E-code error on name collision instead of a silent win.

    pub fn load_wasm_extension(&self, name: &str, wasm_path: &Path) -> Result<(), String> {
        if self.builtin.has_extension(name) {
            return Err(format!(
                "E032: extension '{name}' collides with a built-in extension; \
                 choose a different name or disable the builtin"
            ));
        }
        self.extism.load_module_as(name, wasm_path, None)
    }

    fn call_export(&self, extension_name: &str, export_name: &str, input: &[u8]) -> WasmCallResult {
        // Explicit precedence, never silent: Wasm modules registered by the user
        // take priority; builtins answer only unregistered names.
        if self.extism.is_loaded(extension_name) {
            return self.extism.call_export(extension_name, export_name, input);
        }
        self.builtin.call_export(extension_name, export_name, input)
    }
