publish_json_schema (crates/specforge-emitter/src/schema.rs:825-902) emits only $schema (draft 2020-12), title and description — no $id. Every hand-written schema in schema/ carries a stable $id like https://specforge.dev/schema/specforge.json, so the published Graph Protocol schema is the only one that cannot be referenced by URI, cached by validators, or cited as the dialect a consumer validated against. Because the function output changes with the compiled registries, downstream consumers also cannot pin a revision. Adding a canonical $id (optionally versioned) plus a snapshot test makes the artifact addressable and drift-detectable.
