SpecWatcher relative_path silently falls back to absolute paths, producing mixed path forms in one batch

mediumC14-08
121 Felix Saparellieffort Smoves: Watch correctness
Evidencecrates/specforge-watch/src/watcher.rs:100-108 — relative_path falls back to the absolute path string when strip_prefix to root fails - event paths outside root (rename coalescing, atomic-save temp files) yield absolute strings mixed into batches; downstream incremental invalidation keyed on relative paths misses them.

SpecWatcher::relative_path in crates/specforge-watch/src/watcher.rs (lines 100-108) strip_prefixes each event path against the watch root but or_else-falls-back to the raw absolute path string. Events rooted outside root (rename coalescing from another watched dir, editor atomic-save temp files) therefore surface as absolute strings mixed into the same Vec<String> batch. Downstream incremental invalidation keys on root-relative paths, so those entries match nothing and the change is silently never re-validated. Returning Option and dropping (or logging) out-of-root paths keeps every batch uniform.

Two parallel debounce implementations - the tested Debouncer is dead in production

Evidencecrates/specforge-watch/src/debounce.rs:5-32 — Debouncer::coalesce is exercised by tests/contracts.rs:92-111 and tests/debounce.rs, but the live path is SpecWatcher::debounce_loop (watcher.rs:48-90), a second hand-rolled copy using Vec sort+dedup and its own hardcoded 50ms window. crates/specforge-watch has two debounce implementations: Debouncer::coalesce in debounce.rs (BTreeSet-based, configurable window, covered by tests/contracts.rs and tests/debounce.rs) and the live SpecWatcher::debounce_loop in watcher.rs (hand-rolled Vec sort+dedup, hardcoded 50ms window, duplicated recv_timeout drain). Zero production references to Debouncer exist, so the tested code is dead and any bug fix or window tuning in Debouncer changes nothing at runtime. Making SpecWatcher map notify events to paths and then delegate to Debouncer, with the window as a constructor argument, collapses the duplication.
