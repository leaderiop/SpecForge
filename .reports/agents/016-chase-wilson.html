Sym is a solid interned key — Copy, O(1) eq/hash via Spur, seven focused tests — but the interner stops at names. FieldValue in specforge-parser/src/ast.rs holds String everywhere (String, ReferenceList(Vec<String>), StringList...), so every equality check and lookup on values goes through full string compares. FieldMap::get does a linear scan resolving each key Sym to &str for comparison per call — O(n) per lookup with the toll paid repeatedly across graph building and validation. Meanwhile link_references re-interns every reference target (Sym::new(target_id)) inside the hot loop, and parser constants like Sym::new("verify") are re-interned per entity. Caching the repeated keys as constants, interning reference targets once at parse time, and moving reference targets to Vec<Sym> would quarter-adopt into a real win; a Sym-keyed index inside FieldMap is worth it only if profiling justifies it.

ThreadedRodeo trade-offs undocumented: single RwLock, leak-by-design static resolve, empty-string Default sentinel

Evidenceinterner.rs:5,20-22,75-78 — as_str static only because rodeo leaks forever; Sym::default() interns empty stringparse.rs:128-131,173-175 — missing kind/name fall back to empty-string Sym — nameless entities share identity

Sym::as_str returns &'static str only because the static ThreadedRodeo leaks every interned string forever — a load-bearing invariant documented nowhere in interner.rs. Interner access is a single LazyLock<ThreadedRodeo> whose get_or_intern takes the rodeo's internal writer lock, so parse-heavy multithreaded phases serialize on interning, another unstated cost. And Default for Sym interns the empty string, which combine with parse.rs's unwrap_or_else(|| Sym::new("")) fallbacks for missing kind/name fields: two nameless entities share one identity, and any downstream HashMap keyed by id collapses them together. A documented leak contract, a dedicated MISSING sentinel (distinct from empty-string), and a note on writer serialization would make these trade-offs explicit instead of archaeological.

static INTERNER: LazyLock<ThreadedRodeo> = LazyLock::new(ThreadedRodeo::default);

/// An interned string symbol. Wraps `lasso::Spur` (a `u32` index).
/// `Copy`, `Eq`, and `Hash` are all O(1).
///
/// # Contracts
/// - as_str returns `&'static str` because the rodeo **leaks strings for
///   the process lifetime by design** — never intern unbounded input.
/// - get_or_intern serializes on the rodeo's writer lock; resolve is
///   lock-free. Hot loops should reuse Syms, not re-intern.
/// - Sym::default() is the MISSING sentinel (interned empty string),
///   distinct from any user identifier; `is_missing()` checks it.
#[derive(Clone, Copy, Eq)]
pub struct Sym(Spur);

impl Sym {
    /// Intern a string and return its symbol.
    pub fn new(s: &str) -> Self {
        Self(INTERNER.get_or_intern(s))
    }

    /// True when this is the MISSING sentinel (interned empty string).
    pub fn is_missing(self) -> bool {
        self.0 == Self::default().0
    }

    /// Resolve the symbol back to its string.
    pub fn as_str(self) -> &'static str {
        INTERNER.resolve(&self.0)
    }
