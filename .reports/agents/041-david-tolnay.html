Auditor review

David Tolnay (serde): Serde usage is exemplary — skip_serializing_if, BTreeMap for stable output, serde(default) on every optional protocol field. The rough edge is error handling: four pub fns .expect() on serialization while sibling functions return EmitterError. A library should never have a panic path its own module already knows how to report; make them Result and the scoped wrappers stop double-wrapping.

Serialization output across the emitter and wasm protocol is disciplined and deterministic: optional fields use skip_serializing_if so absent options disappear instead of serializing as null (SchemaField, schema.rs:86-118), exported entities use BTreeMap<String, Value> for stable alphabetical field order (JsonNodeV2.fields, schema.rs:317 area), protocol descriptors like HandshakeResponse use serde(default) on every optional contribution (protocol/types.rs:19-67), and severity enums rename to lowercase.
