Auditor review

An AOT cache that is a byte-for-byte copy with a .aot suffix is the kind of thing that erodes trust in every other performance claim in the README — the cache.rs doc comment even admits it. Wasmtime has Module::serialize/deserialize right there under Extism; wiring aot_cache_path through instantiate is a contained, high-leverage change. I would do that, add a cold-vs-warm benchmark, and only then let the README say AOT.

The 'AOT cache' never compiles anything: cache.rs::cache_wasm_binary copies the original .wasm bytes to <sha256>.aot (its own doc comment admits 'not true AOT compilation'), and ExtismRuntime::instantiate takes _aot_cache_path and ignores it entirely — every load still pays full Wasmtime compilation. has_cached_module only checks whether the copied file exists, so the README's AOT claim is a lie that costs startup time on every CLI and LSP invocation. Wasmtime (under Extism) supports Module::serialize/deserialize for genuine precompiled artifacts; either use that path and honor aot_cache_path, or rename the mechanism to wasm_cache so the docs stop overpromising.

    fn instantiate(
        &self,
        name: &str,
        wasm_bytes: &[u8],
        aot_cache_path: Option<&Path>,
    ) -> Result<(), String> {
        let functions = host_context::build_host_functions(self.host_context.clone());
        let manifest = Manifest::new([Wasm::data(wasm_bytes.to_vec())]);
        let mut builder = PluginBuilder::new(manifest).with_wasi(true);
        if let Some(cache_path) = aot_cache_path {
            // Deserialize a precompiled module if present; otherwise compile
            // once and serialize so subsequent loads skip Wasmtime compilation.
            if let Some(module) = load_serialized_module(cache_path) {
                builder = builder.with_precompiled_module(module);
            } else {
                let compiled = builder
                    .compile_precompiled()
                    .map_err(|e| format!("AOT compile failed for {name}: {e}"))?;
                std::fs::write(cache_path, &compiled)
                    .map_err(|e| format!("cannot write AOT cache: {e}"))?;
                builder = PluginBuilder::new_precompiled(compiled).with_wasi(true);
            }
        }
        let plugin = builder
            .with_functions(functions)
            .build()
            .map_err(|e| format!("Failed to instantiate Wasm plugin {name}: {e}"))?;
        self.plugins.lock().map_err(|e| e.to_string())?
            .insert(name.to_string(), LoadedPlugin { plugin });
        Ok(())
    }
