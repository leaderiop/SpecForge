after — proposed fix
    /// Serialized latest-wins analysis worker.
    async fn enqueue_analysis(&self, uri: Url) {
        let this = self.clone();
        tokio::spawn(async move {
            tokio::time::sleep(Duration::from_millis(DEBOUNCE_MS)).await;
            let content = this.state.read().await
                .document(uri.as_str()).map(|d| d.content().to_string());
            let Some(content) = content else { return };
            // Parse off the runtime; write lock only to commit.
            let result = tokio::task::spawn_blocking(move || {
                this.analyze_snapshot(&uri, &content)
            }).await.expect("analysis worker panicked");
            this.commit_analysis(&uri, result).await;
        });
    }

Explain like I'm 10

Every keystroke hires a new helper who grabs the only pencil and starts a huge pile of work, so nobody else can write. Better: one helper who always switches to the newest request and holds the pencil only briefly.

Proposed solution. serialized latest-wins worker + spawn_blocking.
