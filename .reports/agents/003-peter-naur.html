# First-Attempt Accuracy Eval

The north-star metric (30% baseline -> 70-85% target) measured, not believed.

## Protocol

1. `eval/tasks/` holds N=10 fixed agent tasks against `examples/todo-app`, each with a
   rubric and a reference test in `eval/tasks/expected/`.
2. Arm A (control): the agent gets the repo without the compiled graph.
3. Arm B (treatment): the agent gets `specforge export --format=context` output plus the
   same repo, and may run `specforge query <id> --depth 2`.
4. `eval/run.sh --arm a|b` executes each task in a fresh worktree, logs tokens,
   turns, and first-attempt pass/fail into `eval/results/<date>-<arm>.json`.
5. `eval/score.py` aggregates both arms and prints first-attempt accuracy,
   mean tokens per task, and the delta.

Run after every release; append the row to `eval/RESULTS.md`. If the delta does not
hold, the north star is failing and we say so.
