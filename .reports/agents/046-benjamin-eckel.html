# Extension SDK

Extensions are standalone Rust crates that compile to `wasm32-unknown-unknown`
(the only target the host loads) and depend on `extism-pdk`.

## Current SDK surface

There is no `specforge-extension-sdk` crate yet. Today an extension:

- declares host imports manually with `#[host_fn] extern "ExtismHost"`
  (`host_emit_diagnostic`, `host_read_file`, `host_query_graph` — there is no
  `resolve_ref`);
- embeds its `handshake.json` and nine `describe_*.json` files with
  `include_bytes!`;
- exposes `#[plugin_fn] __handshake` and `#[plugin_fn] __describe`.

A `specforge-extension-sdk` crate with typed protocol structs and attribute
macros is planned (PRD-001, phase 5); until then this document describes the
raw contract exactly as the host consumes it.
