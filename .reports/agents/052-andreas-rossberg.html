Auditor review

serde(default) on handshake fields means a half-written plugin produces a plausible response with all flags false and the host quietly skips describe categories — silent degradation is the worst failure mode for a wire protocol. Combined with four plugins each hand-copying ten JSON blobs with zero schema checks, drift is not a risk but a schedule. I would make contribution_flags required, publish a JSON Schema, and add one conformance test that exercises every builtin's handshake against it; the existing smoke tests are a good seed.

HandshakeResponse decorates contribution_flags, peer_dependencies, and sandbox_policy with #[serde(default)], so a broken or truncated plugin handshake deserializes into a plausible-looking response with empty flags — the host then skips describe categories it should have requested, and nobody notices. On top of that, each of the four plugin crates hand-maintains its handshake.json plus nine describe JSON blobs included via include_bytes!, with no schema and no CI check tying those files to the Rust protocol types; only four smoke tests exist. Silent defaults plus unmaintained fixture copies is exactly how wire drift compounds. Fix: make critical fields required (or validate invariants after deserialize), publish a JSON Schema for handshake/describe, and add a conformance test that runs every builtin's handshake through the schema and the typed structs.
