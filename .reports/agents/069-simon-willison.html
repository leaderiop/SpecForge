069 Simon Willisoneffort Smoves: diagnostic codes documented by explain

The CLI ships specforge explain <code>, a static lookup table covering every E/W/I diagnostic the compiler emits, with plain-English explanations and remediation hints - errors double as documentation. Combined with the specforge.doctor MCP operation (a machine-readable self-check), agents can diagnose the tool's own state and decode failures without any human in the loop. The lookup even handles truncation (I999) and edge cases like missing cache files (I097). This is rare, deliberate agent ergonomics worth protecting.

exemplar — the good pattern
pub fn run(code: &str) -> i32 {
    let normalized = code.to_uppercase();
    match lookup(&normalized) {
        Some((title, explanation)) => {
            println!("\x1b[1m{normalized}\x1b[0m: {title}\n");
            println!("{explanation}");
            0
        }
        None => {
            eprintln!("unknown diagnostic code: {code}");
            eprintln!("hint: codes follow the pattern E### (error), W### (warning), I### (info)");
            1
        }
    }
}
