Unknown field types silently become string

Evidencecrates/specforge-emitter/src/model/mod.rs:103-113 — from_schema_str maps unknown types to String, no warning

ModelFieldType::from_schema_str maps every unrecognized type string to Self::String with a safe-fallback comment and no diagnostic. A typo like stirng in a manifest silently renders as string in every diagram — the model lies quietly instead of surfacing the mistake. Since the registry layer already has a Diagnostic pipeline, return a warning alongside the safe fallback.
