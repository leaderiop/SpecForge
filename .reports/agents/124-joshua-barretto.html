Spanless diagnostics anchor to a nondeterministic HashMap key and can clamp to a range past EOF

mediumC14-13
124 Joshua Barrettoeffort Mmoves: Diagnostic determinism
Evidencecrates/specforge-validator/src/render.rs:25-28,82-86 — Without a span the report anchors to sources.keys().next() - HashMap iteration order, so the anchor file and output vary between runs. In line_col_to_byte_range, when start_line exceeds EOF, start = source.len() and end = min(len).max(start+1) yields a range one byte past the buffer, which ariadne source slicing can panic on. Columns are byte offsets with no UTF-8 boundary guard.

In crates/specforge-validator/src/render.rs, a diagnostic without a span anchors to sources.keys().next() - HashMap iteration order - so the anchor file and rendered output differ run to run, breaking snapshot determinism for an AI-agent surface that diffs reports. Worse, line_col_to_byte_range clamps with start.min(len) then end.min(len).max(start + 1): when start_line exceeds EOF, start becomes source.len() and end is forced one byte past the buffer, a range ariadne can panic on when slicing. Columns are byte offsets with no UTF-8 boundary check, so a column landing mid-character also produces an invalid slice. Anchor spanless reports deterministically (sorted keys or a synthetic unknown source) and clamp end to len with start = end.saturating_sub(1).

When a complaint has no address, the mailman delivers it to whichever house he happens to see first - a different one every day. And if the address is past the end of the street, he writes a number higher than any real house, which can crash the mail room.
