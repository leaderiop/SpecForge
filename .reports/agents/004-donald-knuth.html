/// Enforce the guide's guarantee: every fenced ```spec block in
/// docs/guides parses and validates. Run as `cargo xtask check-doc-snippets`,
/// wired into CI next to fmt and clippy.
fn check_doc_snippets() -> anyhow::Result<()> {
    let mut checked = 0usize;
    for guide in ["docs/guides/authoring-spec-files.md", "docs/guides/spec-cookbook.md"] {
        let text = std::fs::read_to_string(guide)?;
        for (n, block) in extract_fenced_blocks(&text, "spec").enumerate() {
            let tmp = std::env::temp_dir().join(format!("sf_snippet_{n}.spec"));
            std::fs::write(&tmp, &block)?;
            let ok = Command::new(env!("CARGO_BIN_EXE_specforge"))
                .args(["check", "--file"])
                .arg(&tmp)
                .status()?
                .success();
            anyhow::ensure!(
                ok,
                "{guide}: fenced spec block #{n} does not compile\n{block}"
            );
            checked += 1;
        }
    }
    println!("{checked} doc snippets compile");
    Ok(())
}

The mechanism that would realize even the modest 1k-7k context claim is incomplete: crates/specforge-emitter/src/emit.rs:108-112 applies token_budget only when format==Json and schema.is_none(), so specforge export --format=context — the exact what-an-agent-consumes path the docs sell — ignores the budget entirely, and crates/specforge-emitter/src/context.rs serializes every node's full contract/status/verify pretty-printed with no size bound. A marketing story built on portion control cannot ship without the portion-control mechanism and a measured benchmark. Fix: honor the budget in Context and Brief formats, add a token benchmark over todo-app and spec/, and relabel unmeasured savings as projections.
