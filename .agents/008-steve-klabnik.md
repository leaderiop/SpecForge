# 008 — Steve Klabnik

**Cluster:** C2 — DSL & language design
**Roster role:** Rust documentation culture; TRPL co-author
**SpecForge anchors:** authoring guides (`docs/guides/authoring-spec-files.md`, `spec-cookbook.md`, `spec-best-practices.md`); README quality bar (root `README.md` as first-contact artifact)

## Why this engineer
Klabnik helped turn Rust from a promising language into an adopted one largely through documentation: The Rust Programming Language is free, task-first, versioned with the tool, and kept honest by CI. SpecForge's adoption funnel has the same shape and stakes — a ~5-minute authoring guide, a cookbook, troubleshooting, and a README that must convert a skeptic who has seen context-file tools before. Klabnik's standard is the benchmark: docs ship in-tree, are tested against reality, and never assume more motivation than the reader has.
