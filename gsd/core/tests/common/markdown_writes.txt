# kept and own text alike: a write verb and a GSD file name in one sentence of prose, or an output redirect or `tee`
# into one in a shell fence. Its row count is the port's write measure. A row with no hit fails, and so does a hit
# with no row: take a row off in the commit that rewrites its line; never add a row.
