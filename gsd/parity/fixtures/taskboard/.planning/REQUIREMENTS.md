# Requirements: Taskboard

**Defined:** 2026-03-02
**Core Value:** A task is never lost

## v1 Requirements

Requirements for initial release. Each maps to roadmap phases.

### Tasks

- [x] **TASK-01**: A user can add a task with a title
- [x] **TASK-02**: A user can mark a task complete
- [ ] **TASK-03**: A user can list the open tasks

### Storage

- [ ] **STORE-01**: Tasks are saved to disk after every change
- [ ] **STORE-02**: A task title survives a reload unchanged

### Listing

- [ ] **LIST-01**: A user can filter the list by a word in the title

## v2 Requirements

Deferred to future release. Tracked but not in current roadmap.

### Sync

- **SYNC-01**: A board can be kept in step across two machines

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Share a board by link | Needs accounts, which v1 does not have |
