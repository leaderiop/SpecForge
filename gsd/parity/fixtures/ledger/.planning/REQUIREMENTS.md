# Requirements: Ledger

**Defined:** 2026-11-02
**Core Value:** A total is exact to the cent

## v1 Requirements

Requirements for initial release. Each maps to roadmap phases.

### Entries

- [x] **LEDG-01**: A user can add an entry in integer cents with a memo
- [x] **LEDG-02**: The total of the entries is exact to the cent

### Storage

- [ ] **LEDG-03**: Entries survive a restart

### Listing

- [ ] **LEDG-04**: A user can list the entries in the order they were added

## v2 Requirements

Deferred to future release. Tracked but not in current roadmap.

### Reports

- **REPT-01**: A user can see the total per month

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Several currencies | A ledger is one currency |
